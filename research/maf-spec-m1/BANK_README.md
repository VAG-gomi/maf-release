# MAF SPEC-M1 Evidence Bank

This folder is a byte-preserving GitHub copy of the completed `maf_v1/` evidence product from the authored SPEC-M1 experiment. The original bundle's `ARTIFACT_MANIFEST.sha256` remains unchanged and verifies the copied SPEC-M1 tree; `BANK_MANIFEST.sha256` additionally covers this GitHub bank folder, including the bank note and the two release-governing specifications below.

The complete evidence product includes the 240-row T2 table, 13-row T3 summary, computed `PASS` verdict, complete deviation ledger, gate reports, raw worlds/configs/metrics/losses, V-SOFT refit evidence, authored specifications, logs, verifier, and provenance records. The scientific result and evidence files are not modified by the banking operation.

Additional release-governing records are included byte-for-byte at `spec/SPEC-M2-authored.md` and `spec/SPEC-M2-R1-authored.md`; their source is the MAF release tree's `spec/` directory. Their addition is recorded in the outer release ledger as DEVIATION-062's resolution context; the original SPEC-M1 manifest intentionally remains limited to the original evidence tree.

This GitHub folder is a browsable project bank, not the sole archival backup. The original local evidence tree and independently retained ZIP remain authoritative backups. No source code, dependency pin, model behavior, existing tag, or GitHub Release page is changed by this evidence-bank commit.
