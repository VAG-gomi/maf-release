# MAF — Mechanism–Artifact Factorization

This is the canonical home of the **MAF model software**. MAF separates a global mechanism channel from an environment-specific artifact channel and uses a do-mask so the artifact channel is excluded from interventional prediction.

> **Validation boundary:** MAF was validated in synthetic confound-heavy environments with analytic ground truth across 30 worlds using pre-registered criteria and independent execution. It is **not validated on real-world data**.

Real-world validation (SPEC-RW1/RW3): attempted on LaLonde (RCT ATE = 1794.34) and IHDP. Result: MAF did not outperform pooled regression baselines on either dataset. See research/real-world-validation/ for full evidence.

## The actual model code

The reusable model implementation is actual Python source in [`src/maf/model.py`](src/maf/model.py). It defines the public `MAFModel` class, including initialization, fitting, environment adaptation, interventional prediction, observational prediction, artifact norms, and artifact scores.

The supporting package source is:

| Source file | Role |
|---|---|
| [`src/maf/model.py`](src/maf/model.py) | Core `MAFModel` implementation and do-mask behavior |
| [`src/maf/worlds.py`](src/maf/worlds.py) | Deterministic synthetic-world generation used by the package |
| [`src/maf/metrics.py`](src/maf/metrics.py) | RMSE, M-PSI, M-DAUROC, and related metric functions |
| [`src/maf/io.py`](src/maf/io.py) | Configuration and provenance persistence helpers |
| [`src/maf/__init__.py`](src/maf/__init__.py) | Public package exports and version `1.1.1` |

The package has nine actual tests under [`tests/`](tests/), including determinism, do-mask behavior, metric correctness, generator behavior, fitting guards, quarantine initialization, refit warnings, regression, and treatment-value validation.

## Install and use the model

Use Python 3.12 or newer:

```bash
python -m pip install .
```

Minimal usage:

```python
import maf

world = maf.generate_world(2000)
model = maf.MAFModel(seed=world["keys"]["world"] + 7000)
model.fit(world["environments"])
predictions = model.predict_interventional(x, tau)
```

The exact public behavior and guard conditions are documented in [`docs/API.md`](docs/API.md). The worked example is [`examples/run_example.py`](examples/run_example.py), with its expected output described in [`docs/EXAMPLE.md`](docs/EXAMPLE.md).

## Results and interpretation

The concise empirical card is [`docs/EMPIRICAL_CARD.md`](docs/EMPIRICAL_CARD.md). It reports the exact 13-statistic SPEC-M1 summary and the computed `PASS` label. The K1/K2 ablation gaps are part of the authored synthetic experiment; they are not claims of general real-world performance.

The package release is hardened with explicit not-fitted guards, treatment-value validation, deterministic environment ordering, refit warnings, and a do-mask regression test. The exact pinned runtime dependencies and support boundary are recorded in [`pyproject.toml`](pyproject.toml), [`CHANGELOG.md`](CHANGELOG.md), and [`verification/VERIFY.md`](verification/VERIFY.md).
